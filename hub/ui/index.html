管理工具

已安裝的工具、網站連結，以及可以安裝的官方工具。

設定

存在 Hub 的資料夾；由 Hub 啟動的工具會自動套用。

外觀

深淺色
強調色
切換後，嵌入的工具會立即跟著變。
主題風格 純色
質感
紋理
預設是石墨（中性灰，藍色只用在強調色）。強調色可以和任何風格搭配；光暈、液態玻璃的光斑會跟著強調色。不影響嵌入的工具頁面。

Python 直譯器

貼上 python.exe 的完整路徑，按「檢查」確認版本。

進階

重設 Hub 設定
清除外觀、Python 路徑、匯入的本機工具登記、網站連結與「顯示在 Hub」設定。已安裝的工具程式與工具自己的資料都會保留。

選擇包含 tool.json 的資料夾，也可以直接貼上路徑。
資料夾選擇視窗已開啟，請在該視窗選擇資料夾（可能在其他視窗後面）。
儲存後可以在「管理工具」的「⋯ → 更換圖示」換成圖示、emoji、圖片或網站圖示。

更換圖示

Windows 可以按 Win + . 開啟 emoji 面板。
圖片會存在 Hub 的資料夾，不會放進任何 repo。

按下「抓取」時，Hub 會連到這個網站下載它的圖示（favicon.ico），存在本機；之後不需要再連網。
